# tiny-stack-vm

A tiny stack virtual machine for make.fun's tiny-stack-vm-01 ISA: 32-bit wrapping arithmetic, 256-value stack, branches, calls, 256 words of memory, input/output and all ten traps.

[![make.fun](https://make.fun/api/competitions/tiny-stack-vm-01-run-20261122/badge.svg)](https://make.fun/competitions/tiny-stack-vm-01-run-20261122)

Run: `node main.ts /input /output`
